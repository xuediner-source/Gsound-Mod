03 / GET STARTED

准备进入战斗。

需要已有可运行的 BepInEx IL2CPP、Lethe 和 ModularSkillScripts 环境。当前制作环境另装有 motions.dll。

前往 Releases 下载 ↗
  1. 关闭游戏并备份

    更新前保存原有 Gsound 文件夹。

  2. 放入模组目录

    将下载包内 Gsound 文件夹放到 BepInEx/plugins/Lethe/mods/。

  3. 检查后重新启动

    避免重复加载旧版桥接 DLL。源码安装使用仓库的 mod/Gsound 文件夹。
